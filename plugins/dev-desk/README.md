# dev-desk

A Claude Code mod for the desktop and mobile apps. A pixel crab with headphones gets a little desk right above the [effortless](https://github.com/HeyCubit/effortless) band, over the prompt box:

- **Claude idle:** the desk is empty and the crab walks back and forth along the band.
- **Claude working:** the crab sits behind the laptop and types; the lid's logo blinks and the coffee steams.

It also puts the effortless row first in the band, so the desk stands on it, and hides the ponytail mod's row from the band (ponytail stays enabled). Without effortless installed the desk simply sits on top of whatever band rows you have.

The terminal draws nothing: the scene is an SVG, which only the apps draw. `prefers-reduced-motion` stops the animation.
